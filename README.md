# Roblox 版《光明之魂》类型 3D ARPG — v6

一款俯视角偏第三人称的地牢 ARPG：选职业、学技能，城镇休整、买药、强化武器，走进传送门下地牢，一波波刷怪、打 Boss、升级爆装备。整个游戏只有**一个服务端脚本文件**（v4 起另加一个一次性粘贴的客户端小脚本，见安装第 6 步），粘贴一次就能玩。

## 安装步骤（照着做，约 2 分钟）

1. 打开 **Roblox Studio**，新建一个 **Baseplate（基板）** 模板的 Place。
2. 在右侧 **Explorer（资源管理器）** 里找到 **ServerScriptService**，鼠标悬停点 **+** 号，添加一个 **Script**。
3. 打开这个 Script，**把里面默认的代码全部删掉**（默认只有一行 `print("Hello world")`）。
4. 把 `ShiningSoulServer.server.lua` 的**全部内容**粘贴进去。
5. 点顶部的 **Play（▶ 运行）**。
6. **（v4 新增，只做这一次）** 在 Explorer 里找到 **StarterPlayerScripts**，鼠标悬停点 **+** 号，添加一个 **LocalScript**，删掉默认代码，把 `UIClient.client.lua` 的**全部内容**粘贴进去。这个小脚本负责把界面点击转发给服务端、播放背景音乐，v5 起还负责转发技能热键 Q / E / R；不装它游戏照样能玩，只是界面按钮点不动、没有背景音乐、热键放不出技能。**注意：装过 v4 版 UIClient 的玩家，v5 需要把这个 LocalScript 的内容换成新版**（多了热键转发），服务端脚本和它都要更新到 v5。

运行后场景会自动生成：城镇广场、喷泉、商店、房子、导师和训练假人，城外一片野外（道路、池塘、篝火），野外尽头是紫色传送门大石拱门，门后是石墙地牢——你什么都不用摆。出生点在城镇，往北出城门、穿过野外、走进拱门就进地牢，第一波怪自动开打；地牢里的蓝色传送门会把你送回拱门外。

> 注意：脚本必须放在 **ServerScriptService**，放错地方（比如 Workspace 或 StarterPack）不会运行。地牢在城镇远处（地图坐标 Z = -110），在城镇里看不见是正常的，走传送门过去。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 / 视角 | WASD / 鼠标（Roblox 默认第三人称） |
| 挥剑攻击 | 装备 Sword 后鼠标左键（或点工具栏 1 再点左键） |
| 火球术 | 装备 Fireball 后左键，耗 20 点 Mana |
| 喝药水 | 装备 Drink Potion 后左键，回 55 点血 |
| 买东西 | 走到商店摊位前，按提示按 **E**（ProximityPrompt） |
| 背包 / 穿装备 | 点左上角 HUD 下方的 **Bag** 按钮打开背包，点装备格子穿上、点已穿戴栏卸下 |
| 背景音乐 | 在背包面板顶部切换：Auto（城镇/地牢自动换曲）/ Calm / Battle / Off |
| 选择 / 更换职业 | 点左上角 **Class** 按钮打开职业面板，点职业卡片即可转职（等级、金币、装备都保留） |
| 技能面板 / 升级技能 | 点 **Skills** 按钮打开技能面板，有技能点时点技能右边的 **+** 升级（每升 1 级得 1 点） |
| 释放技能 | 按 **Q / E / R**，或点屏幕下方技能栏的技能按钮（需先在技能面板学到 1 级） |
| 弓（弓手） | 装备 Bow 后左键，箭矢自动瞄准最近的怪 |

工具栏在屏幕下方，出生自动发放。没选职业前是老三样（剑 / 火球 / 药水）；选了职业后按职业发：战士、圣骑士 = 剑 + 药水，法师 = 法杖（火球）+ 药水，弓手 = 弓 + 药水。

## v6 更新日志（本次）—— 怪物技能与攻击模式 + 大地图（非战斗城镇 + 野外）

- **怪物不再无脑贴身蹭人**，每种怪都有自己的攻击模式（状态机：接近 / 保持距离 / 蓄力 / 出手 / 恢复）：
  - **史莱姆（跳跳怪）**：一蹦一跳地接近；每约 3.5 秒一次**跳跃扑击**——先压扁蓄力 0.4 秒，然后跳到你所在的位置，落地 4 码内造成伤害，走开就能躲；平时贴身伤害有 0.8 秒间隔，不再持续磨血
  - **哥布林（突袭怪）**：跑得快，接近时有 30% 概率横向绕步；在 10–18 码距离会**蓄力突进**——先闪白一下（0.35 秒前摇），然后高速冲到你面前造成伤害，之后 1 秒慢速恢复期，是集火它的窗口
  - **骷髅（远程风筝怪）**：会主动保持 22–30 码距离（你进它退、你退它进，还会慢慢绕圈），每 2.2 秒朝你**射一根骨头投射物**（实体飞行、速度可躲）；被你贴身到 6 码内只会弱力挥一下然后逃开
  - **精英怪**：多了一个**砸地技能**——在你脚下亮起红色预警圈（半径 7，0.7 秒），站在圈里不走就会吃一记重砸，约 6 秒一次
  - **骷髅王 Boss 三技能 + 狂暴**：① **大砸地**（红圈半径 10、预警 1 秒、伤害更高，约 7 秒一次）；② **召唤**：血量降到 66% 和 33% 时各召唤 2–3 只骷髅/史莱姆小弟（场上小弟最多 4 只，小弟算波次击杀数、经验金币减半）；③ **骨头齐射**：每约 5 秒朝你扇形射出 3 根骨头；④ 血量低于 30% **狂暴**：移速 +40%、技能冷却 ×0.65、眼睛变红发光、名字带 (Enraged)
  - 所有预警圈都是半透明红色圆盘、会闪烁，出圈即躲开；所有骨头投射物都是实体、按步进做距离判定，可以靠走位躲掉；怪物的一切伤害（扑击/突进/骨头/砸地/近战）都走同一条减伤管线，护甲、胸甲减伤、职业减伤、荆棘反伤照常生效
- **城镇 = 正式的非战斗区（休整区）**：
  - **职业导师 NPC**：广场东边高台上站着导师，走到跟前按 E（提示 “Change Class”）直接重开选职业面板，和点 Class 按钮效果完全一样
  - **训练假人 ×3**：广场西边的稻草假人，能打、会冒伤害数字和火花、血条会掉，但**永远打不死**（血量自动回满）、不还手、不给任何奖励，也不影响地牢波次——随便试技能试装备
  - **告示牌**：城门边一块木牌，写着基本操作（移动 / 攻击 / 技能 Q E R / 背包 / 商店 / 怎么去地牢）
  - 还有：长椅 + 篝火的社交角落（篝火照样回血）、广场四角花坛、栅栏外一排街道房子、广场变大了
- **野外区（城镇 ↔ 地牢之间）**：一条石板路从城门通到地牢大门，路边有栅栏、树、石头、一口池塘，路边一处篝火可以回血；4 只野史莱姆在固定点附近游荡（离家太远会自己回去，打死给正常经验金币，10 秒后在家点重生），它们和地牢波次互不影响，地牢的怪也永远不会跑到野外和城镇来
- **地牢入口改到野外尽头的大石拱门**：两根石柱 + 横梁 + 紫色传送门，走进去就下地牢；原来城镇门边的小传送门改成了一块装饰用的紫色符文石（不再传送）。地牢里的回城传送门会把你送回拱门外的野外，动线是：城镇 → 野外 → 地牢 → 野外
- **世界边界**：整个地图外围加了一圈岩石山 + 松树，不再是无边无际的一块板

## v5 更新日志（本次）—— 职业系统：4 职业 × 3 可升级技能

- **4 个职业（参考暗黑 2 的构筑思路）**：进游戏自动弹出选职业面板（也能点左上角 **Class** 按钮随时重开转职）。每个职业有独立的基础修正，直接作用在原有公式上：
  - **战士 Warrior**：生命 ×1.4、近战伤害 ×1.25、法力 ×0.7，工具 = 剑 + 药水
  - **法师 Mage**：法术伤害 ×1.4、法力 ×1.8（法力池 180）、生命 ×0.75，工具 = 法杖（火球）+ 药水
  - **弓手 Archer**：远程伤害 ×1.3、移速 17.5、生命 ×0.95，工具 = **新武器弓** + 药水（箭矢自动瞄准 + 轻微追踪，70 码内必中向）
  - **圣骑士 Paladin**：生命 ×1.2、近战 ×1.05、法力 ×1.1、自带 5% 减伤，工具 = 剑 + 药水
  - 转职保留等级、金币、装备；**技能等级按职业分别保存**，切回来构筑还在
- **每职业 3 个技能，0–5 级**：每升 1 级得 1 个技能点，在 **Skills** 面板点 **+** 升级（面板写清当前/下一级数值）。释放：**Q / E / R** 热键或点屏幕下方技能栏（按钮实时显示剩余冷却秒数）
  - 战士：**旋风斩**（9 码内全体 120%+20%/级武器伤害，人物原地旋转 + 三道剑气）/ **冲锋**（突进 16 码，穿过敌人 100%+25%/级）/ **战吼**（10 秒 +15%+3%/级伤害、+10%+2%/级减伤）
  - 法师：**冰霜新星**（11 码 60%+15%/级法伤 + 减速 50% 持续 2+0.3/级秒）/ **陨石**（目标处 0.8 秒红圈预警，随后 200%+40%/级范围爆发）/ **传送**（朝向/最近敌人瞬移 18 码，地牢内不会穿墙出界）
  - 弓手：**多重射击**（3 + 每 2 级 1 支扇形箭，每支 80%）/ **穿透射击**（直线贯穿所有敌人，150%+30%/级）/ **箭雨**（目标区域 5 波，每波 40%+10%/级）
  - 圣骑士：**祝福之锤**（金锤绕身旋转 4+0.5/级秒，碰到敌人 70%+15%/级）/ **治疗**（自己和 14 码内队友回 25%+5%/级最大生命）/ **荆棘光环**（开关型光环：反弹敌人近战伤害的 10%+4%/级，脚下有金色光圈）
- **怪物减速支持**：冰霜新星的减速走怪物 AI 的移速通道，怪会肉眼可见地慢下来（并闪冰蓝色）
- **存档扩展**：职业、技能点、四个职业各自的技能等级、荆棘光环开关状态一起存档
- **客户端脚本更新**：UIClient 新增 Q / E / R 热键转发（聊天打字时不会误放技能）；装过旧版的需要把 LocalScript 内容换成 v5 新版（见安装第 6 步）

## v4 更新日志 —— 装备系统 + 音效 + 背景音乐

- **装备掉落（带稀有度）**：4 个部位——武器（+攻击，剑和火球都吃）、头盔（+生命上限）、胸甲（+% 减伤，和护甲点叠加、总减伤封顶 75%）、鞋子（+移速）。4 个品质——白装（Common）/ 蓝装（Rare）/ 紫装（Epic）/ 橙装（Legendary），属性一档比一档高。掉率：普通怪 8%（白 70% / 蓝 30%）；精英怪 60%（蓝 60% / 紫 35% / 橙 5%）；Boss 必掉（紫 70% / 橙 30%）。掉落物是带底座的发光球，颜色 = 品质，头顶飘着装备名，走过去碰一下就进背包（背包满了会提示 Bag full 并留在地上）
- **背包 + 穿戴界面**：左上角 Bag 按钮打开面板——左边是 4 个已穿戴栏（点一下卸下），右边是 4×6 背包格子（点一下穿上，换下来的自动回背包），格子边框和文字颜色就是品质色，写着装备名和属性。背包上限 24 件
- **穿上立马不一样**：穿戴立刻体现在角色身上——头盔是焊在头上的圆顶 + 帽檐（橙装带皇冠尖刺和光源），胸甲是前后两块胸板（蓝装以上胸口有发光宝石），鞋子是两只金属靴；手里的剑按武器品质重造型（白=素钢、蓝/紫/橙=对应颜色发光刃 + 光源，橙装剑最长）；头盔/鞋子的血上限和移速也立刻生效
- **音效**：挥剑、砍中、怪物死亡、捡东西、喝药水、升级、受伤都有声音（砍中带随机音调变化，不会听腻）。用的都是 Roblox 经典内置音效和公开素材 ID；万一某个 ID 失效，那一声就不响，不会报错
- **背景音乐可选择**：背包面板顶部切换 Auto / Calm / Battle / Off。Auto 模式下在城镇放舒缓曲、进地牢自动换战斗曲；选 Calm 或 Battle 就全程一首；Off 静音
- **存档扩展**：背包和已穿戴装备一起存档，退出重进装备还在身上
- **一次性客户端脚本**：v4 的界面点击和音乐播放需要安装步骤第 6 步的 `UIClient.client.lua`（LocalScript，只粘一次，以后更新服务端脚本不用再动它）

## v3 更新日志 —— 美术与地形设计版（玩法数值不变）

- **武器造型**：剑不再是方块——皮握把 + 金色护手 + 剑首，钢刃随 Tier 变色变长，Tier 4 以上刃口带霓虹光晕和光源；火球工具改成法杖（木杖身 + 橙色霓虹法球 + 光源）；药水改成圆玻璃瓶（红药液 + 瓶颈 + 软木塞）
- **砍杀特效**：挥剑时身前扫出一道霓虹弧光（-70° 到 +70°），握把同步扭转；打中怪物爆 6 颗霓虹火花；怪物死亡时身体炸开、四肢乱飞并淡出，不再原地消失
- **怪物造型**：史莱姆是半透明果冻体 + 发光内核 + 带高光的眼睛，还会一弹一弹地压扁拉伸；哥布林有尖耳朵、黄眼睛、胳膊和腰布；骷髅有肋骨条、黑眼窝和下巴；骷髅王戴金色皇冠、披红披风；精英怪仍是金色版
- **城镇设计**：圆形石板广场 + 通往传送门和商店的石板路；房子带暖黄发光窗、深色门、烟囱；两个正规摊位（四柱 + 双色斜雨棚 + 挂牌，分别写着 ITEM SHOP 和 BLACKSMITH，药水摊还摆了展示药瓶，铁匠摊有铁砧）；喷泉中心加了发光宝珠；3 盏路灯带真实光源
- **城镇安全区**：木栅栏围住整个城镇，北边（传送门一侧）留了带门梁的大门，传送门立在门外，进出关系一眼看懂；传送门加了石框、紫色火花粒子和光源
- **地牢设计**：深色棋盘格石地板、贴墙石柱、火把带粒子火焰；入口有石拱门，进门是一段窄走廊（扼守点，可以堵着打）；场内多了掩体石柱和矮墙，可以绕柱拉怪
- **地牢安全点（篝火）**：2 处篝火——一处在入口走廊外、一处在场地西侧中段（石圈 + 木柴 + 火焰 + 地面绿色光圈标出范围）。站在光圈里每 0.5 秒回 6 点血，怪物不回血，残血可以撤回篝火休整
- **危险区**：东南角有一片岩浆池（橙红发光，很显眼），站进去每 0.5 秒烧 8 点血，绕开走；不在路上、不在出生点和篝火边
- **高台**：西侧边缘有一座带台阶的石台，可以站上去占高处
- **氛围杂物**：岩石、骨头堆、木箱、木桶散布在场地边缘
- **光照**：全场改成黄昏（约 17:48 的暖色夕阳 + 暖色环境光 + 轻雾），城镇依然够亮

- **商店**：药水 30 金币/瓶；铁匠强化剑，价格随等级涨（150 × 当前等级），最高 Tier 5，剑的颜色和伤害同步提升
- **HUD**：左上角面板实时显示等级、经验、金币、Mana、药水数和当前波次；升级/清波/Boss 出现时有顶部横幅播报
- **多人**：以上全部按玩家独立结算，多人同场可一起刷波次（波次是全服共享的）
