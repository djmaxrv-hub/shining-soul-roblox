# Roblox 版《光明之魂》类型 3D ARPG — v2

一款俯视角偏第三人称的地牢 ARPG：城镇休整、买药、强化武器，走进传送门下地牢，一波波刷怪、打 Boss、升级爆金币。整个游戏只有**一个服务端脚本文件**，粘贴一次就能玩。

## 安装步骤（照着做，约 2 分钟）

1. 打开 **Roblox Studio**，新建一个 **Baseplate（基板）** 模板的 Place。
2. 在右侧 **Explorer（资源管理器）** 里找到 **ServerScriptService**，鼠标悬停点 **+** 号，添加一个 **Script**。
3. 打开这个 Script，**把里面默认的代码全部删掉**（默认只有一行 `print("Hello world")`）。
4. 把 `ShiningSoulServer.server.lua` 的**全部内容**粘贴进去。
5. 点顶部的 **Play（▶ 运行）**。

运行后场景会自动生成：城镇广场、喷泉、商店、房子、紫色传送门，以及远处的石墙地牢——你什么都不用摆。出生点在城镇，往北走进紫色传送门就进地牢，第一波怪自动开打。

> 注意：脚本必须放在 **ServerScriptService**，放错地方（比如 Workspace 或 StarterPack）不会运行。地牢在城镇远处（地图坐标 Z = -110），在城镇里看不见是正常的，走传送门过去。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 / 视角 | WASD / 鼠标（Roblox 默认第三人称） |
| 挥剑攻击 | 装备 Sword 后鼠标左键（或点工具栏 1 再点左键） |
| 火球术 | 装备 Fireball 后左键，耗 20 点 Mana |
| 喝药水 | 装备 Drink Potion 后左键，回 55 点血 |
| 买东西 | 走到商店摊位前，按提示按 **E**（ProximityPrompt） |

工具栏在屏幕下方：1 = 剑，2 = 火球，3 = 药水（出生自动发放）。

## v2 更新日志（本次）

- **打击感**：打中怪物会冒黄色伤害数字（上飘淡出），怪物身体闪白一下
- **精英怪**：普通怪约 12% 概率变精英——金色身体、名字带 Elite，血量 ×2.5、伤害 ×1.5，经验/金币 ×3
- **装备掉落**：精英和 Boss 必掉装备拾取物——护甲没满掉护甲（每件 +1 点，最高 5 点，每点减伤 8%），满了掉力量水晶（永久 +3 伤害，剑和火球都吃）；普通怪也有 5% 概率掉力量水晶。HUD 新增 Armor / Power 两行
- **存档**：等级、经验、金币、药水、剑等级、护甲、力量全部存档（DataStore），退出重进接着玩；每 60 秒自动存一次。注意：Studio 里测试存档需要在「体验设置 → 安全性」里打开 **API 服务访问**，没开也不报错，只是这次不保存；发布到线上后自动生效

## v1 已包含的系统

- **地图**：城镇（广场、喷泉、4 栋房子、树、商店摊位）+ 独立地牢（石地板/石墙、柱子、6 支带 PointLight 的火把），双向传送门
- **战斗**：剑的正面扇形攻击 + 击退，冷却 0.38 秒；火球是真实飞行的投射物，命中判定在服务端
- **成长**：经验/等级（升级阈值随等级增长，升级 +20 血上限并回满）、金币、Mana 自动回复、药水
- **怪物 3 种 + Boss**：史莱姆（慢、血少）、哥布林（快）、骷髅（硬），第 5 波出大 Boss「Skeleton King」；怪物有头顶血条和名字，会追最近的玩家并攻击
- **波次系统**：波次越高怪越多越强；清波给全场金币奖励；打完 Boss 后地牢进入下一轮回，整体难度再涨
- **掉落**：击杀自动给经验和金币，25% 掉药水拾取物、20% 掉回血球，碰一下就捡
- **商店**：药水 30 金币/瓶；铁匠强化剑，价格随等级涨（150 × 当前等级），最高 Tier 5，剑的颜色和伤害同步提升
- **HUD**：左上角面板实时显示等级、经验、金币、Mana、药水数和当前波次；升级/清波/Boss 出现时有顶部横幅播报
- **多人**：以上全部按玩家独立结算，多人同场可一起刷波次（波次是全服共享的）

## 已知限制 / 下一步（v3 候选）

- **没有收费点**：Game Pass（双倍经验、VIP 等）还没接，需要你提供 Pass ID 后在脚本里填。
- **怪物是方块拼的**：用 Part + WeldConstraint 拼的简模，没有动画；后续可换成带动画的 R15 模型。
- **近战是扇形范围判定**，没有挥剑动画和音效；火球、击中、升级的音效待加。
- **职业系统未做**：v1 只有战士路线（剑 + 火球 + 药水），法师/弓手分支、技能树、装备栏（捡装备换装）留到后续版本。
- **地牢只有一张图**：后续可做多层地牢、随机房间和精英怪词缀。
